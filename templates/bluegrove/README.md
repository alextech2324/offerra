# Bluegrove

PHP lander in the same dictionary-ML shape as Vespera and Fortis: one tree, `lang/*.php` packs (27 languages), `integration/send.php` for CRM.

Navy-and-green AI investing site. Default URL is English; other languages use `/de/`, `/it/`, … Home has a market tape, hero form, three steps, a sample signal, registration, and FAQ. Inner pages: platform, pricing, team, contact, privacy, terms.

Stock copy uses `{brand}` for the funnel name. Minimum deposit is described by region, not a fixed amount. Generated offers rewrite `includes/config.php`. The registration form does not take a card.

Preview: `/preview/bluegrove/`.
